# 啥子记账

**一款纯本地、无广告、无账号的极简记账App。**

> 数据保存在你的手机里，不联网、不上传、不需要登录任何账号——记账这件事，就该这么简单。

- **3秒记一笔**：大按钮直达，常用类目一屏选完
- **预算圆环**：每月预算消耗一眼看清，接近上限变黄、超支变红
- **周期记账**：房租、工资、会员费设置一次，自动按日记账
- **深色模式** 不同主题色可选择
- **数据自由**：一键导出CSV，随时备份恢复

## 下载安装

前往 [**Releases 页面**](../../releases) 下载最新的 APK 安装包：

1. 手机浏览器打开 Releases 页面，点击 APK 文件下载
2. 点击安装时，系统会提示"允许安装未知来源应用"——允许即可
3. 打开App

> 按手机 CPU 架构下载：绝大多数手机选 **arm64** 版（约 34MB）；老款 32 位手机选 armeabi-v7a 版；不确定就下 universal 整包（约 86MB）。支持 Android 7.0 及以上系统，覆盖安装不影响已有数据。

## 功能一览

### 记账
- **常用类目直选**：饮食、交通、购物、医疗、休闲娱乐，列表一屏选完
- **更多分类**：居家物业、通讯话费、人情往来、金融保险、学习进修、宠物、旅行度假
- **自定义分类**：想要啥类目自己加，图标支持自定义
- **备注、日期、账户**：备注原地输入，支持现金/微信/支付宝/银行卡及自定义账户

### 预算
- **每月总预算 + 分类预算**，双层管控
- 首页预算圆环实时显示消耗进度，接近上限变黄、超支变红
- 预算按自然月计算，每月1日自动清零重新累计

### 周期记账
- 房租、工资、视频会员这类**固定收支**，设置一次
- App打开时自动按日期记入账单，漏开几天也会自动补齐

### 统计
- 本月支出/收入/结余/日均支出，一屏总览
- 收支趋势、分类占比环形图、分类排行、日历热力图

### 数据安全
- **本地SQLite存储**，单文件、可备份
- 退到后台自动备份（滚动保留最近3份）
- **导出 CSV/Excel**，字段与主流记账App对齐，随时迁移

## 技术栈

| 层 | 技术 |
|---|---|
| 框架 | React Native 0.81 + Expo SDK 57 |
| 语言 | TypeScript |
| 本地存储 | expo-sqlite（SQLite 单文件） |
| 图表 | react-native-svg 自绘 |
| 构建 | Gradle 9.3 + JDK 17 |

## 从源码构建

```bash
# 环境要求：Node.js 18+，并完成 React Native 安卓环境配置（JDK 17 + Android SDK）
npm install
npx expo prebuild -p android        # 生成原生工程
cd android
./gradlew.bat assembleRelease       # 产物在 app/build/outputs/apk/release/
```

开发调试：

```bash
npm install
npx expo start                      # 配合 Expo Go 扫码，或安卓模拟器
npm test                            # 逻辑层单元测试
```

## 隐私

- 不收集任何数据、无任何网络请求、无任何追踪
- 全部数据存储在App私有目录，卸载即清除
- 支持导出的字段：`日期,类型,分类,金额,账户,备注`
